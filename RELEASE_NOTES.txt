Random Splitting Sort - Release Notes

Highlights
- Refactored into reusable library structure:
  - include/Random_Splitting_Sort.hpp
  - src/Random_Splitting_Sort.cpp

- Added deterministic/randomized correctness tests in tests/tests.cpp.
- Added CI pipeline (.github/workflows/ci.yml) to build and test automatically.

- Configurable algorithm knobs:

  - sample-size

Quality
- Local test runner: passing.
- CI workflow: configured for build + tests + smoke benchmark.
